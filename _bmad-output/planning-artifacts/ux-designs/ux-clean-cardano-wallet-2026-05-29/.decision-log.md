# Decision Log — Cardano UTXO Consolidator & Dust Cleaner

This file records all architectural and UX design decisions made during the UX planning phase.

## Initial Decisions (2026-05-29)

- **[DEC-001] dApp-only Architecture**: The application operates solely as a CIP-30 connected dApp. No independent wallet management or persistent database backend is introduced for MVP v1.
- **[DEC-002] Multi-Asset Spam Isolation vs. Burning**: Standardizing two modes of junk token resolution:
  1. *Isolated Junk Box* (Default, low cost): Gathers all junk tokens into a single multi-asset UTXO, releasing 90%+ locked ADA back to the user, and isolating the UTXO in local memory to prevent accidental spending.
  2. *Full Burn* (Advanced): Sends assets to an unspendable address, sacrificing the remaining min-ADA to clear the assets permanently from the wallet.
- **[DEC-003] LocalStorage Cache for Trusted Assets**: To enable user customization, trusted assets manually marked by the user will be stored in the browser's `LocalStorage`.
