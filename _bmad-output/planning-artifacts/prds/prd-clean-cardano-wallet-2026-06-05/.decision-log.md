# Decision Log — ADASweep Classification Engine PRD

## Log of Decisions

### [2026-06-05] PRD Workspace Initialization
- **Decision:** Tạo workspace mới cho PRD tập trung vào Asset Classification Engine (không update PRD cũ ngày 29/05).
- **Rationale:** User yêu cầu "viết PRD lại" cho riêng classification flow — scope khác biệt so với PRD cũ (bao phủ toàn bộ UTXO consolidator).

### [2026-06-05] Scope Boundary
- **Decision:** PRD này chỉ cover classification/detection flow, không bao gồm consolidate/burn.
- **Rationale:** User nói rõ "ý tôi flow ở đây là cái phần phân loại".
- **Status:** Approved

### [2026-06-05] Protocol Parameters — Fetch từ Blockfrost API
- **Decision:** Dùng Blockfrost `/epochs/latest/parameters` để fetch protocol params thay vì hardcode.
- **Rationale:** SDK `@hydra-sdk/transaction` có `TxBuilderOptions.params` nhưng không có built-in fetch method. Blockfrost đã được tích hợp sẵn.
- **Status:** Approved

### [2026-06-05] DEX Strategy per Network
- **Decision:**
  - **Mainnet:** Minswap Aggregator API (covers 17+ DEX protocols) làm primary.
  - **Preprod:** Blockfrost UTXO scanning tại known pool addresses + VyFinance testnet API.
  - **Cả 2:** UTXO scanning làm fallback universal.
- **Rationale:** Minswap Aggregator là giải pháp mạnh nhất cho mainnet. Preprod không có aggregator, phải dùng UTXO scanning.
- **Status:** Approved

### [2026-06-05] Architecture Pattern
- **Decision:** DexService abstraction (interface + implementations per network), không hardcode provider trong store.
- **Rationale:** Dễ test, dễ thêm DEX provider mới, dễ mock cho unit test.
- **Status:** Approved

### [2026-06-05] Cache TTL
- **Decision:** Liquidity cache TTL = 5 phút. Retry 1 lần nếu API fail.
- **Rationale:** Tránh rate-limit DEX API, không re-fetch quá thường xuyên.
- **Status:** Approved
